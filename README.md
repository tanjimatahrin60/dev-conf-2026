# DevConf 2026

A modern developer conference website designed to showcase DevConf 2026, featuring conference speakers, event details, ticket plans, and a live hackathon arena. The website provides a clean and engaging interface for developers, founders, and technology enthusiasts.

---

## 🌐 Live Website

- **Live Site:** https://tanjimatahrin60.github.io/dev-conf-2026/

---

## 📌 Project Overview

DevConf 2026 is a conference-themed website created to present information about a developer conference. Visitors can explore featured speakers, conference tracks, ticket plans, and hackathon opportunities through a structured and visually appealing layout.

---

## ✨ Key Features

- Modern developer conference website layout
- Navigation menu with conference sections
- Hero section with event introduction
- Featured speaker profiles
- Multiple conference ticket plans
- Standard, Pro, and Team pricing options
- Live Hackathon Arena section
- Hackathon prize pool and team information
- Beginner, Intermediate, and Pro tracks
- Registration and call-to-action sections
- Footer with additional links and branding

---

## 🛠️ Technologies Used

- **HTML5** — Used to build the structure and content of the website
- **CSS3** — Used for styling, layouts, typography, spacing, and visual presentation

## 📦 Dependencies

This project is a static frontend website and does not require any external frameworks, libraries, or packages.

### Requirements

- HTML5

No package installation or dependency management is required.

## 🚀 Local Development Setup

No installation or build process is required to run this project locally.

### 1. Clone the Repository

    git clone https://github.com/tanjimatahrin60/dev-conf-2026.git

### 2. Open the Project Folder

    cd dev-conf-2026

### 3. Launch the Website

Open the `index.html` file in your preferred web browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.
